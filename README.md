# 🏢 Sistema de Control Vacacional - Coca-Cola

¡Bienvenido al repositorio de mi Proyecto Final de Java! 
Este es un sistema de escritorio interactivo diseñado para gestionar y 
calcular los días de vacaciones de los empleados de la empresa Coca-Cola, 
dependiendo de su antigüedad y su departamento.

Este proyecto está basado en el curso del canal de **La Geekipedia De Ernesto**.

## 📁 Estructura del Proyecto

Los archivos se encuentran organizados dentro de la carpeta Proyecto-final:

*   📄 Bienvenida.java: Interfaz de inicio de sesión con captura de nombre del usuario administrador.
*   📄 Terminos.java: Pantalla de aceptación de políticas de uso con validación de casilla de verificación (*JCheckBox*).
*   📄 Vacaciones.java: Formulario principal para ingresar datos del trabajador
    (Nombre, Apellidos, Departamento y Antigüedad) y calcular automáticamente sus días de vacaciones.
*   📦 ProyectoFinal.jar: Archivo ejecutable de la aplicación.
*   🖼️ Recursos Visuales: Logotipos y fondos oficiales de la interfaz
    (coca-cola.png, coca-cola-blanco.png, logo-coca.png, icon.png).

## 💾 Ejecución Directa
El proyecto incluye el archivo compilado listo para usar. 
Puedes descargar el archivo **ProyectoFinal.jar** que se encuentra dentro de la carpeta 
y ejecutarlo directamente en tu computadora (requiere tener instalado Java Runtime Environment).

## 🛠️ Tecnologías Utilizadas
*   **Lenguaje:** Java 
*   **Interfaz Gráfica:** Java Swing / AWT (Diseño construido 100% mediante código puro)
*   **IDE de Desarrollo:** NetBeans
